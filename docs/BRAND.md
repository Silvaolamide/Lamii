# Lami Brand Guidelines

## Brand name

The customer-facing product name is **Lami**.

Use **Lami** in all user-facing UI, copy, page titles, onboarding, notifications, emails, marketing language, and product documentation intended for users.

### Repository name

The GitHub repository remains **`Silvaolamide/Lamii`**. Do not rename the repository as part of this branding change unless that is explicitly requested later.

The repository/package/database identifiers may retain `lamii` where changing them would create unnecessary technical risk. This is an internal implementation detail, not the customer-facing brand.

## Naming rules

### Correct

- Lami
- Lami app
- Lami users
- Lami profile
- Lami Discovery
- Lami Waves
- Lami Chats

### Avoid in customer-facing copy

- Lamii
- Lamii app
- Welcome to Lamii
- Join Lamii
- Lamii profile

## Visual identity

Lami's visual identity follows the selected second discovery/profile design reference.

The core visual direction is:

- Deep teal and blue-black foundations.
- Strong, saturated teal rather than pale/light teal.
- Strong teal blended into a much darker teal underneath.
- Saturated coral/red, orange, purple, and other accent colors used deliberately.
- High contrast and strong readability.
- Rich gradients and blended color transitions.
- Rounded cards with depth.
- Subtle borders, glows, and layered surfaces.
- Large expressive photography.
- Bright, confident action controls.
- Fluid motion and responsive touch interactions.

Avoid washed-out pastel interfaces, weak teal, excessive low-contrast glassmorphism, and unrelated colors without a coherent token system.

## Product personality

Lami should feel:

- social
- energetic
- modern
- confident
- welcoming
- human
- local
- fluid
- premium without feeling exclusive

The interaction quality should feel comparable to polished mobile social/discovery products, while remaining distinctly Lami. Do not copy another product's branding, artwork, wording, or exact interface.

## Core discovery language

The preferred discovery experience is **not** a full-screen swipe-only card stack.

Lami Discovery should communicate:

1. How many people are around the user.
2. The active discovery radius.
3. A collection of medium-sized, scrollable profile cards.
4. Tap a person to inspect the full profile.
5. Wave/Like/Pass actions where supported by the product rules.
6. A smooth path from discovery to connection and chat.

## AI implementation rule

When an AI agent changes the UI, it must use **Lami** as the customer-facing brand name. It should preserve `lamii` technical identifiers when those are repository/package/database/internal identifiers unless an explicit migration is requested.

The existing `docs/UI-UX-PLAN.md` remains the detailed UI/UX source of truth; this file establishes the brand naming rule and should be read alongside it.
